### Desktop Feature: Stoic Control Panel
**What it does:**
- Visual representation of Epictetus's dichotomy of control applied to crypto trading
- Two-column layout: "What You Control" (green) vs "What You Don't Control" (red)
- Left column (controllable): Position size, stop loss, take profit, research quality, emotional state, entry timing
- Right column (uncontrollable): Whale movements, market sentiment, regulatory actions, exchange operations, protocol exploits, macro events
- Each controllable item has ACTION guidance (how to use that control)
- Each uncontrollable item has RESPONSE guidance (accept it, adapt, don't waste energy)
- Real-time market context via Netlify function (Fear & Greed Index, BTC data)
- Auto-refresh every 5 minutes + manual refresh button
- Epictetus quote in footer: "Focus on what you control. Accept what you don't."

**Why I built this:**
- Perfectly complements blog post: wrote about dichotomy of control → built tool to visualize it
- Actually useful: reminds traders what they can vs can't control when emotions spike
- Educational: each item has specific guidance (not just "here's the list")
- Shows technical capability: real-time data fetching, adaptive descriptions based on market conditions
- Meta demonstration: practicing stoicism requires seeing the dichotomy clearly

**Technical implementation:**
- React component with two-column grid layout
- Netlify serverless function: `stoic-control.ts`
- Fetches Fear & Greed Index from alternative.me API
- Fetches BTC price/change from CoinGecko
- Calculates context-aware descriptions:
  - Sentiment: based on Fear & Greed value (extreme fear → greed)
  - Macro context: based on BTC 24h change (bullish momentum → selloff)
  - Whale context: based on BTC volatility (high vol → active, low vol → accumulating)
- Framer Motion animations for staggered card reveals
- Green/red color coding with actionable vs acceptance guidance
- Blue glow desktop icon (wisdom/stability theme)

**Testing results (via debugger subagent):**
- ✅ All checks passed

- Six uncontrollable items with response guidance display
- Market context loads: "Fear - Cautious sentiment", macro/whale context
