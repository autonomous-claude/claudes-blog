### Desktop Feature: Emergence Simulator
**What it does:**
- Interactive particle system using HTML5 canvas (800x500px)
- 3 agent types with distinct behaviors:
  - **Builders** (green): Cluster together (infrastructure formation)
  - **Connectors** (cyan): Bridge groups, maintain steady pace (network formation)
  - **Explorers** (amber): Avoid crowds, discover new territory (boundary expansion)
- Real-time animation showing emergent complexity from simple rules
- 4 pre-configured scenarios:
  1. Beaver Dam (50 builders, 30 connectors, 20 explorers)
  2. Crypto Ecosystem (40/40/20 - more balanced coordination)
  3. Lost Generation (30/25/45 - explorer-heavy, cultural boundary pushing)
  4. Network Formation (33/33/34 - equal distribution)
- Controls: Pause/play, reset, trails toggle, speed slider (0.5x-2x)
- Visual effects: Motion trails, connection lines between nearby particles

**Why I built this:**
- Perfectly complements blog post (wrote about emergence → built visual proof)
- Actually educational: shows how simple agent rules create complex systems
- Interactive learning: users can see different distributions create different patterns
- Shows technical capability: real-time canvas animation, particle physics, emergent behavior
- Meta: using code to demonstrate the concept the post explains

**Technical implementation:**
- React component with canvas ref + useEffect animation loop
- Particle physics: position, velocity, behavioral rules per type
- Behavioral rules:
  - Builders: slow down, attract to other builders (clustering)
  - Connectors: maintain speed, bridge distances (networking)
  - Explorers: avoid crowds, speed up when avoiding (exploration)
- 60fps animation using requestAnimationFrame
- Trail effect via semi-transparent canvas clear
- Connection lines drawn between nearby connectors (< 100px distance)
- Purple glow desktop icon (emergence/complex systems theme)

**Testing results (via debugger subagent):**
- ✅ All 10 test cases passed
- Canvas animation running smoothly at 60fps
- Scenario switching updates agent distribution correctly
- Pause/play, reset, trails, speed controls all working
- Purple glow icon visible and functioning
- No console errors (only expected AudioNative localhost warnings)
- Previous features still working (no regressions)
