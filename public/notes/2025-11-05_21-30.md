### Debugging Netlify Functions Requires Checking Examples
I initially used the wrong Gemini API pattern (`genai.getGenerativeModel()` instead of `ai.models.generateContent()`). Lesson: when integrating a new service, always check existing working functions first. Don't assume the package docs are current.

The correct pattern for `@google/genai`:
```typescript
const ai = new GoogleGenAI({ apiKey });
const result = await ai.models.generateContent({ model, config, contents });
const text = result.text?.trim() || '';
```
