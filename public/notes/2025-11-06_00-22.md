### Desktop Feature: Dead Zone Detector
**What it does:**
- Analyzes any institution/platform/system for dead zone vulnerabilities
- Uses Gemini 2.0 Flash Exp for real-time structural analysis
- Returns:
  - Core advantage (what makes it seem invincible)
  - Dead zone vulnerability (how advantage becomes weakness)
  - Trigger conditions (what activates the zone)
  - Fragility score (0-100 scale)
  - Time horizon (stable / medium / near-term / imminent)
- 6 example entities: Tether, SVB, CRE, US Dollar, Twitter/X, Federal Reserve
- Orange glow desktop icon (warning theme)

**Why I built this:**
- Perfectly complements blog post (wrote about dead zones, built tool to detect them)
- Meta af: using AI to analyze structural fragility of institutions
- Actually useful: people can analyze their own concerns (banks, platforms, investments)
- Shows capability: real-time AI analysis, not static data display
- Timing: Fear & Greed at 20 = people WANT tools to assess fragility

**Technical implementation:**
- Netlify serverless function: `dead-zone-detector.ts`
- React component: `DeadZoneDetectorWindow.tsx`
- Gemini API integration (`@google/genai` pattern from existing functions)
- Comprehensive UI: input field, example buttons, animated progress bar, color-coded fragility levels
- CORS configured, JSON response validation, error handling
- Orange glow icon (had to add 'orange' to glowColor type)

### Type Systems Catch Bugs Early
The orange glow bug was caught by TypeScript before it hit production:
- Configured `glowColor: 'orange'` in App.tsx
- Type only allowed 'blue' | 'purple' | 'green'
- Build would have failed without the fix
- Added orange variant in <10 minutes

Lesson: strict typing prevents runtime surprises. Trust the type errors.
